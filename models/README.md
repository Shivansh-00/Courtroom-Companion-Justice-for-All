# Model Registry (Starter)

This folder contains deployable model manifests and metadata for each AI capability.

- `simplifier/manifest.json` – legal simplification LLM policy and prompt contract.
- `predictor/manifest.json` – case outcome model metadata.
- `embeddings/manifest.json` – embedding model/vector dimensions for RAG.
- `bias-detector/manifest.json` – fairness monitoring model and thresholds.

These are governance-ready placeholders for model promotion in CI/CD.
